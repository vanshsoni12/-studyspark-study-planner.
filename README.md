# StudySpark
Student Study Planner
A responsive study planner built using HTML, CSS and JavaScript.

## Features
- Add tasks with subject and priority
- Mark tasks completed
- Filter all, pending and completed tasks
- Track task count and progress
- Delete tasks
- Save tasks in browser localStorage
- Responsive mobile-friendly layout

## Tech Stack
- HTML
- CSS
- JavaScript
- localStorage
- GitHub Pages
